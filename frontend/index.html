Coding Philosophy & Mindset

The core principles guiding how I write software, architect APIs, and approach complex problems.

1. Deterministic Math & Zero Float Error

Financial, inheritance, or analytical calculations must never rely on inexact float operations. Using rational fraction math yields 100% verified correctness every time.

2. Zero Dependency Bloat

Prefer native Web APIs, clean ES6+ JavaScript, and lightweight edge runtimes over heavy npm dependencies. Less bloat means faster load times, fewer vulnerabilities, and higher reliability.

3. Purposeful AI Engineering

AI should augment human workflow with crisp, contextual intelligence. I integrate Gemini models via secure server-side routes to provide real value rather than visual gimmicks.
